# Антидедлайн

Бесплатное адаптивное PWA-приложение: превращает большой дедлайн в небольшие ежедневные шаги.

## Запуск

Сайт опубликован через GitHub Pages. После включения Pages из ветки `main`, папка `/(root)`, он доступен по адресу:

https://whedeshka.github.io/antidedline/

## Возможности

- создание проекта: название, описание, дедлайн, объём работы;
- выбор доступного времени в день и темпа;
- автоматическое разбиение на ежедневные шаги;
- отметка выполненного и индикатор прогресса;
- пересчёт оставшихся шагов после пропущенного дня;
- хранение проектов локально в браузере;
- установка на главный экран телефона и базовая офлайн-оболочка.

## Важно

GitHub Pages — статический хостинг. План в текущей версии формируется встроенным алгоритмом, без внешнего ИИ и без платных сервисов. Не добавляйте секретные API-ключи в публичные файлы.

Данные сохраняются в localStorage этого браузера. Между устройствами синхронизации пока нет. Очистка данных сайта может удалить проекты.

## Локальный запуск

Из корня проекта: `python -m http.server 8000`, затем откройте http://localhost:8000.
