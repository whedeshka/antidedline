# Антидедлайн

Бесплатное адаптивное PWA-приложение для превращения дедлайнов в небольшие ежедневные шаги.

## Возможности
- проекты с описанием, объёмом, дедлайном, временем на день и темпом;
- планирование встроенным алгоритмом без API;
- опциональный ИИ-планировщик на Gemini 2.5 Flash;
- пересчёт оставшихся шагов с сохранением выполненных;
- хранение проектов и личного API-ключа только в localStorage браузера;
- установка на главный экран телефона.

## Включить ИИ
1. Открой приложение и нажми значок «?» в правом верхнем углу.
2. Создай личный API-ключ в [Google AI Studio](https://aistudio.google.com/app/apikey).
3. Вставь его в поле «Личный Gemini API-ключ» и сохрани.
4. Создавай проекты как обычно — приложение попробует составить план с помощью Gemini. При ошибке автоматически вернётся к встроенному планировщику.

## Важные ограничения и приватность
- GitHub Pages — статический хостинг. В этой версии запросы к Gemini идут напрямую из браузера, поэтому ключ хранится в localStorage и может быть просмотрен владельцем браузера/через инструменты разработчика. Это персональный режим «свой ключ», а не безопасная схема для публичного сервиса с общим ключом.
- Не вставляй сюда ключ, которым пользуются другие люди, и не коммить API-ключ в GitHub.
- У Gemini API есть бесплатный тариф с лимитами; доступность моделей и квоты могут меняться. Google указывает, что данные бесплатного тарифа могут использоваться для улучшения продуктов.
- Проекты и ключ остаются в конкретном браузере. Синхронизации между устройствами нет.
