Антидедлайн

Подключи Gemini, чтобы ИИ составлял персональный план по описанию задания. Без ключа приложение продолжит работать в обычном режиме.

Ключ хранится только в этом браузере и используется для прямых запросов к Google. Не вставляй сюда чужой или рабочий ключ. Запросы идут в Gemini API; на бесплатном тарифе действуют лимиты, а данные могут использоваться Google для улучшения продуктов.

Получить ключ бесплатно: открой Google AI Studio, создай API key и вставь его сюда. Не публикуй ключ в GitHub и не отправляй его другим людям.
